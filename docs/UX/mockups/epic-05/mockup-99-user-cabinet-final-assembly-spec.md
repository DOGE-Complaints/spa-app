This mockup assembles the complete DOGEstonia user cabinet.

Unlike previous mockups, this is a real runtime screen.

It demonstrates:

```text
final information architecture
component hierarchy
visual balance
real user experience
```

# 5) Visual Hierarchy

Priority order:

```text
1 Civic Status

2 Story Activity

3 Contribution Layer

4 Account

5 Wallet
```

The screen should visually communicate:

```text
Participation first
Identity second
Infrastructure third
```

---

# 6) Empty State Handling

The mockup should represent a realistic active user.

Not an empty account.

Not loading state.

Not error state.

Use populated example data.

---

# 7) Visual Rules

Use established DOGEstonia language:

```text
dark civic-tech aesthetic
glass panels
white typography
muted gray support text
DOGEstonia yellow accents
enterprise SaaS appearance
```

Avoid:

```text
social feed layout
crypto dashboard
portfolio UI
gamification
leaderboards
token balances
```

# 9) Design Goal

Within 5 seconds a user should understand:

```text
Who am I?
Am I verified?
What stories have I submitted?
What contributions are recorded?
What infrastructure is available?
```
