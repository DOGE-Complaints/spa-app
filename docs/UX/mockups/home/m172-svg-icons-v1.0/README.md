All masters use viewBox 0 0 24 24 and currentColor, no raster, text, font, scripts, embedded image, background rectangle or external dependency. Stroke width 1.75, rounded caps/joins; scalable to 16–24 CSS px. selected-check.svg uses a filled circle and contrasting check; its check uses #FFFDF8 for contrast on the accent fill. Preserve contrast if changing the accent. Verify with actual host palette before rollout.

SVG drawing size is not hit target: interactive hosts retain ≥44 CSS px. Icons accompany localized labels; decorative instances should be hidden from accessibility APIs, while icon-only controls need an accessible name from the existing shell. This package does not change navigation, form delivery, copy or APIs.

Telegram paper plane is a contact cue in the sheet’s line language, not a certified official logo export. No new DOGEstonia logo/mascot has been drawn: use the accepted theme-specific transparent PNG brand masters separately. Header/footer DOGEstonia wordmarks are therefore intentionally not included.
