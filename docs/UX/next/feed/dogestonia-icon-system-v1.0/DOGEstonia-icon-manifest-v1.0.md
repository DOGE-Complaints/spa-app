## Decisions and release boundaries

- Rounded 2 px outline family, `support` heart, and Share in PostActionStrip approved by product owner on 2026-10-06.
- `acknowledge` uses a listening ear; `agree` a circled check; `disagree` a circled cross; `off-topic` a departing conversation arrow. These are proposals requiring semantic approval before release. Labels are primary.
- Gap-8 masters (`empathy`, `concern`, `sad`, `outraged-situation`, `useful-fact`, `insightful`, `needs-evidence`, `aggressive`) landed 2026-10-14 from [DOGEstonia-Gap8-reactions-v1.0](../../../../tasks/backlog-stories/component-reactions/DOGEstonia-Gap8-reactions-v1.0/); promoted to `public/icons/next-feed/reactions/`. Labels remain primary.
- Concept-ready and API-blocked glyphs can be imported only when their component capability exists. An SVG alone does not enable the feature.
- `off-topic` and `aggressive` are comment-only. No bookmark, map cluster, logo or character included.
- Shared masters are one actual file with component transforms/styles; no duplicate alias files.
- SHA-256 for all produced files appears in `SHA256SUMS.txt`, except that checksum document itself. A file cannot contain a stable checksum of its own bytes.
