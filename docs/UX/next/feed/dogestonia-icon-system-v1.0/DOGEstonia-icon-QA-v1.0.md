# DOGEstonia icon QA v1.0

## Performed

- Parsed every SVG as XML; checked 24×24 viewBox, standalone SVG, `currentColor`, no embedded raster, text, script, external reference, gradient or hardcoded SVG colors.
- Rendered complete light and dark sheets and an optical size sheet at 16, 20, 24, 32 px. Visually inspected the sheets; compact reaction shapes are proposals pending product review.
- Checked token-driven light/dark rest, hover, focus, selected and disabled examples; the components still own their actual UI state and 44 px touch targets.
- Compared icon inventory to the supplied Component & Variants Specification and Asset Manifest; excluded speculative features and recorded blocked capabilities.
- Confirmed agreement/disagreement use opposite shapes as well as catalog labels; off-topic uses a distinct departing arrow; no Facebook/Meta or provider artwork was copied or cropped.
- SHA-256 hashes generated for masters, previews and documents.

## Still required in implementation

- Product approval of `acknowledge`, `agree`, `disagree`, `off-topic` metaphors. `support` heart and family style are approved.
- Browser and device verification in the actual components at 16/20/24/32 px, zoom, forced colors, focus, selected and disabled states; SVG-sheet inspection is not an assistive-technology test.
- Accessible localized names in ET/RU/EN, labelled picker, and reaction target eligibility. Icon-only buttons receive names on their buttons.
- Visual contrast checks against actual component surfaces and status/reaction text; decorative reaction accents do not serve as sole meaning.
- Data-contract gates for attachment reads, reactor people and Connect; these are not enabled merely because a symbol exists.
