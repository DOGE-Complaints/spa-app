# STORY-SPA-ID-12 — Каталог иконок/визуалов (M128)

> Референс для вёрстки: все **функциональные** визуалы экранов handoff-сабмита, снятые с артборда [M128](../../../UX/mockups/epic-04/mockup-128-story-draft-handoff-submit-state-sheet-spec.png). Для каждого — контекст использования, **зафиксированное имя файла** (чтобы вёрстка ссылалась на стабильный путь) и промпт для генерации в растре на прозрачном фоне.
>
> **Scope:** только продуктовые иконки состояний A–H/E0. **Не** включены артборд-служебные визуалы (стрелки-коннекторы, боксы Flow Mapping / Error States / Route&API, маркеры ✓/✕ в панелях Privacy/Principles) — это документация артборда, не UI.

## Конвенции
- **Директория (fixed):** `public/icons/story-handoff/` (существует `public/icons/`, сейчас пуст — это дом для набора).
- **Имя файла:** `ic-<kebab>.png`, один ассет = один файл.
- **Формат:** PNG с альфой (прозрачный фон), квадрат **256×256** (+ по возможности `@2x` 512×512), padding ~15%, без текста/рамки/тени.
- **Стиль (design-system):** тонкая линия (stroke ~2px), скруглённые концы/стыки, flat, enterprise civic-tech (Lucide/Linear-подобно), под тёмный UI DOGEstonia.
- **Цвета (verified-токены):** бренд-жёлтый **#f5c542** (≈#f5c518, [CivicStatus.css:32](../../../../src/components/CivicStatus/CivicStatus.css#L32), [PhoneVerificationFlow.css:80](../../../../src/components/PhoneVerification/PhoneVerificationFlow.css#L80)); нейтраль (foreground) **#f5f7fa**; тёмная база #12161e. **success green / error red** — согласовать с токеном приложения (в проверенном CSS пока не зафиксированы — помечено TBD).
- **Reuse (НЕ генерировать заново):** бренд-логотип/щит — уже есть [`public/assets/DOGEstonia-logo-big.png`](../../../../public/assets/DOGEstonia-logo-big.png) / `-fallback.svg`; флаг-бейджи ET/RU/US — [`public/assets/ET.svg`](../../../../public/assets/ET.svg) и т.д. (бейдж языка в State C = текст-пилюля, не иконка).
- **a11y:** декоративные иконки — `aria-hidden="true"`; смысловые (success/error/lock) — с `aria-label` или текстом рядом.
- **⚠️ Тема:** растр PNG не перекрашивается под light/dark. Нейтральные линейные иконки в идеале держать как `currentColor` SVG (тинтуются CSS). Растр — по запросу; при мультитеме вернуться к SVG-варианту.

## Заметки
- **Консолидация (опц.):** поля #4–#6 (Title/Summary/Description) при упрощении дизайна можно свести к 1–2 нейтральным «текстовым» иконкам; #1 spinner переиспользуется в A и E. Финальный набор фиксировать при вёрстке (T03/T04).
- **Спиннер:** если анимация делается CSS/SVG (крутящийся ринг), растр-PNG не нужен — тогда #1 исключить. Уточнить на реализации.
- **success/error цвета:** завести токены в CSS до генерации #14/#18/#19 (сейчас в проверенном CSS их нет — не выдумываем hex).
- **Методология:** этот каталог — новый **обязательный артефакт для каждой UI-стори** (наряду с таблицей текстов/L10N): иконки перестали «забываться». Держать рядом со стори, ссылка — в самой стори.
