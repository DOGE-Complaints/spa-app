## Краткое описание

Логотип DOGEstonia содержит фон канонического Night UI цвета `#0B1320`, но размещён на поверхностях другого оттенка. Из-за несовпадения вокруг логотипа виден прямоугольный фон, и знак выглядит вставленной картинкой, а не органичной частью интерфейса.

Проблема особенно заметна потому, что header, левая область и footer используют иной оттенок, тогда как цвет внутри логотипа совпадает с фоном main content.

## Фактический результат

- Вокруг логотипа видна подложка собственного цвета.
- Логотип не сливается с фоном поверхности, на которой расположен.
- Main content и shell используют несогласованные оттенки относительно брендового asset.
- Брендовая зона выглядит технически неаккуратно и визуально распадается на слои.

## Ожидаемый результат

- Логотип воспринимается как естественная часть header/shell без видимого прямоугольника вокруг него.
- Цвет поверхности под логотипом точно соответствует фону asset либо сам asset имеет реальную прозрачность.
- Система фоновых оттенков DOGEstonia применяется последовательно во всех публичных состояниях.
- Канонический цвет `#0B1320` используется согласно единому правилу, а не по-разному в соседних областях.

## Шаги воспроизведения

1. Открыть любую публичную страницу DOGEstonia с логотипом в header или shell.
2. Сравнить цвет прямоугольной области внутри/вокруг logo asset с цветом непосредственной поверхности под ним.
3. Сравнить эту поверхность с main content, header, левой областью и footer.
4. Наблюдать видимую границу фоновой подложки логотипа.

## Пользовательское влияние

Дефект не блокирует действие, но сразу снижает ощущение качества и целостности продукта. На публичной демонстрации он выглядит как ошибка экспорта asset или незавершённая сборка дизайн-системы.

## Product Rule

`#0B1320` — канонический базовый Night UI цвет DOGEstonia.

Для брендовой зоны должно выполняться одно из двух условий:

1. поверхность непосредственно под непрозрачным логотипом имеет точно `#0B1320`; или
2. используется логотип с реальным прозрачным фоном, корректно работающий на утверждённой поверхности.

Предпочтительный устойчивый результат — прозрачный asset плюс формально закреплённая система surface colors.

## Acceptance Criteria

- [ ] Вокруг логотипа отсутствует видимая прямоугольная подложка.
- [ ] Фон логотипа и непосредственной поверхности совпадает пиксельно либо asset имеет реальную прозрачность.
- [ ] `#0B1320` закреплён и используется как канонический Night UI token в согласованных областях.
- [ ] Header, main content и footer используют намеренно определённую систему оттенков без случайных расхождений.
- [ ] Логотип корректно выглядит на всех публичных маршрутах.
- [ ] Результат проверен на desktop и narrow/mobile состояниях.
- [ ] Красные placeholder-иконки не входят в проверку и не влияют на закрытие этого bug report.

## Priority

**Fix before public demo.** Это не функциональный blocker, но заметный брендовый дефект первого уровня.
